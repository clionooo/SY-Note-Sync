# SY Note Sync · 思源笔记插件

思源笔记多设备同步插件。配合自建的 **SY Note Sync 服务端**（Go + SQLite）使用：
所有思源实例（iOS / Windows / macOS / Docker 网页端）只连接这一个同步服务，
设备之间零直连。

## 安装

### Docker / 桌面端（有工作空间目录）

```bash
cp -r dist/* "<思源工作空间>/data/plugins/sy-note-sync/"
# 重启思源 → 设置 → 集市 → 已下载 → 启用「笔记同步」
```

### iOS / Android（移动端）

移动端思源没有「从文件装插件」的入口，两条路：

1. **推荐**：手机上的思源连接 NAS 上那个 Docker 工作空间（远程模式）——
   插件装在服务端工作空间里，手机自动可用。
2. **本地工作空间**：把 `sy-note-sync` 整个目录通过「文件」App 放进
   `<思源工作空间>/data/plugins/` 下，然后重启思源启用。

## 配置（每台设备一次）

打开插件设置面板（顶栏图标，或 设置 → 集市 → 已下载 → 设置）：

1. 填「同步服务地址」，点 **测试连接** —— 确认网络通
2. 填「管理令牌」和「设备名称」，点 **注册并保存** —— 密钥自动落盘
3. 新设备点 **首次全量同步**，把服务端的笔记拉回本机

> 两个令牌别混：
> **管理令牌** = 部署服务端时设的管理员密码（`SYNCSRV_ADMIN_TOKEN`），只用于注册设备和进后台；
> **设备密钥** = 每台设备自己的通行证，注册时服务端自动发放。
> 如果手机端注册失败，可以在服务端后台「设备 → 密钥」里查看已注册设备的密钥，手动粘贴。

## 设置面板

| 页签 | 内容 |
|---|---|
| 连接 | 服务地址 / 设备名 / 管理令牌 / 设备密钥；测试连接、注册并保存 |
| 同步 | 自动同步开关、暂停、防抖延迟、排除笔记本、立即同步、全量同步、创建快照 |
| 设备 | 本机信息、增量游标、最近推送/拉取时间、回收站与块历史、未解决冲突 |
| 日志 | 最近 200 条运行日志；一键「复制诊断信息」（反馈问题请带上它） |
| 关于 | 版本信息 |

## 常见问题

**测试连接失败 / 注册失败**
先确认手机和 NAS 在同一网络，浏览器能打开 `http://<NAS IP>:58282/healthz`。
错误提示里会带上具体原因（超时 / 连不上 / 令牌错误）。

**改了笔记另一台设备没反应**
1. 看服务端后台「变更日志」有没有记录：有记录说明推送成功，问题在另一端的写回
2. 看插件「设备」页签的在线状态和「日志」页签
3. 另一端点一次「首次全量同步」兜底

**两端同时离线改了同一段**
重新联网后先推的一方正常，后推的一方会弹「冲突」窗，选保留哪一版即可。
也可以在服务端后台的「冲突」页处理。

**同步是按什么单位？**
按思源「块」（Block ID），不是 md 文件。所以插件监听的是块变更事件，
写回时也用 `dataType=dom` 以保住块 ID。
