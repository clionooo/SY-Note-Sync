# SY Note Sync

**思源笔记中心化多设备同步方案** —— Go 后端同步服务（Docker）+ 思源笔记前端插件。

对标 [Fast Note Sync](https://github.com/haierkeys/obsidian-fast-note-sync) 的架构，但同步单元是思源的**块（Block ID）**
而不是 md 文件（思源底层是块数据库，没有文件系统可遍历）。

所有思源实例（iOS / Android / Windows / macOS / Docker 网页端）**只连接这一个同步服务**，
设备之间零直连、无 P2P。服务端只记录变更与快照，不直接读写思源的数据库——
思源的读写全部由插件调用官方公开 API 完成。

```
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│ iOS 思源 APP │      │ Windows 思源 │      │ Docker 思源  │
│   (插件)     │      │   (插件)     │      │   (插件)     │
└──────┬──────┘      └──────┬──────┘      └──────┬──────┘
       │   HTTP 推/拉  +  WebSocket 实时下发
       └──────────────┬────┴────────────────────┘
                      ▼
        ┌───────────────────────────────┐
        │   SY Note Sync 服务 (Go)      │  ← 部署在 NAS / 任意 Docker 主机
        │   设备注册 · 密钥鉴权          │
        │   块变更流水 + 最新块状态       │     SQLite
        │   冲突检测（双版本保存）        │
        │   快照 / 回滚 / 回收站          │
        │   Web 管理后台 · 分享链接       │
        └───────────────────────────────┘
```

## ✨ 功能

### 同步
- **块级实时同步**：监听思源块变更事件，防抖后批量推送；远端变更经 WebSocket 实时下发并写回
- **多设备**：每台设备一把独立密钥；服务端维护在线状态与最后活跃时间
- **离线可用**：待推送队列持久化，断网/切后台/重启都不丢；重连后按游标增量补齐
- **冲突处理**：两端离线改了同一块 → 服务端保存两个版本 → 插件弹窗选择保留哪版
- **首次全量同步**：新设备一键把服务端全部块拉回本机
- **全量上传**：服务端还是空库时，把本机每篇文档整体推上去
- **手动 / 自动同步**：可设防抖延迟、可暂停、可排除指定笔记本
- **版本历史与回收站**：任意块的历史版本可查可恢复；被删的块永久留痕、一键恢复
- **快照与回滚**：整库快照，回滚后自动通知所有在线设备重新全量同步
- **附件同步**：块里引用的图片/音频/视频（`assets/` 下的文件）一起同步。
  推块前先问服务端缺哪些（只传缺的），收到远端块后自动把缺的附件下下来；
  可设单个附件大小上限，超限的跳过不传

### 管理后台（内嵌，无需额外部署）
- **看板**：设备数 / 在线数 / 同步块数 / 变更数 / 冲突数 / 数据库体积 / 最近活动
- **设备管理**：查看密钥、改名、加备注、重置密钥、删除
- **变更日志**：分页 + 按设备/操作/关键字筛选，点块 ID 直接看历史版本
- **笔记本浏览**：按笔记本 → 文档 → 块内容三层查看
- **附件管理**：缩略图预览、按路径筛选、大小统计、下载、删除
- **分享链接**：把某篇文档或某个块生成公开只读页（可设密码、有效期、访问计数）
- **服务端设置**：站点名、是否允许注册、是否允许分享、自动快照保留数
- **实时刷新**：后台与同步服务之间另开一条 WebSocket，设备上下线/新变更即时反映
- **深浅色主题 + 响应式**：手机浏览器上也能用

### 其它
- **单二进制部署**：前端资源全部 embed 进 Go 二进制，镜像约 20MB
- **自动建表 / 自动迁移**：老版本数据库可以直接升级，不用重建
- **JSON 导出**：后台一键导出全部块状态与设备列表

## 🚀 快速开始

### 1. 部署服务端（NAS / 任意 Docker 主机）

```bash
git clone https://github.com/clionooo/SY-Note-Sync.git
cd SY-Note-Sync
# 改 docker-compose.yml 里的 SYNCSRV_ADMIN_TOKEN
docker compose up -d --build
curl http://<NAS的IP>:58282/healthz     # 返回 ok
```

管理后台：`http://<NAS的IP>:58282/admin`（令牌 = `SYNCSRV_ADMIN_TOKEN`）

### 2. 构建插件

```bash
bash scripts/build.sh plugin
# 产物：dist/sy-note-sync-v2.0.0.zip（通用） / -ios.zip（iOS 用）
```

### 3. 安装插件

**Docker / 桌面端**（有工作空间目录）：

```bash
cp -r plugin/dist/* "<思源工作空间>/data/plugins/sy-note-sync/"
# 重启思源 → 设置 → 集市 → 已下载 → 启用「笔记同步」
```

**iOS / Android**：见 [docs/DEPLOY.md](docs/DEPLOY.md#移动端安装)

### 4. 配置（每台设备一次）

插件设置面板（顶栏图标，或 设置 → 集市 → 已下载 → 设置）：

1. 填「同步服务地址」→ 点 **测试连接**
2. 填「管理令牌」+「设备名称」→ 点 **注册并保存**（密钥自动落盘）
3. 新设备点 **首次全量同步**；服务端还是空库时，先在内容最全的设备上点 **全量上传**

## ⚠️ 与 v1 的协议兼容

服务端**同时接受** `content`（v2）和 `markdown`（v1）两个字段名，老插件不会被改名卡住。
但 v1 插件有几个致命 bug（见 [CHANGELOG](docs/CHANGELOG.md)），建议全部升级到 v2。

### 附件同步的边界

- 只同步 `assets/` 目录下的文件，其它目录不碰
- 超过「单个附件大小上限」的文件会跳过并记日志（不会静默丢）
- **附件只增不删**：块删了附件仍保留在服务端，避免误删素材；要清理由后台手动删
- 服务端删除附件后，各设备**本地已下载的文件会保留**（不会远程删你本地的文件）
